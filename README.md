I'm a Computer Science student at **IPB University** working across

Most of my recent work involves building systems that support real operational
workflows at university scale — from internal ERP and student-facing platforms

# Data Infrastructure

For OMB IPB 63, student information came from multiple sources and
operational units.

I worked on preparing, cleaning, validating, and normalizing data for
approximately **8,000 incoming students** so the same structured data
could be reused across different services.
